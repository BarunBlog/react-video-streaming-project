# Video-Streaming-System

This is the completed frontend component of the video streaming application built with ReactJs.

## Technology used

ReactJs, React Router Dom, DashJs.

# Installation

1. Clone the repository:
2. Change directory to django-video-streaming-project by running `cd react-video-streaming-project`
3. Set up following environment variables:

```
REACT_APP_API_URL=http://127.0.0.1:8000/api

```

Create a .env file in the root directory and provide the required values for environment variables.

# Install Dependencies

`npm install`

# Start the Development Server

`npm start`
Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.\
You may also see any lint errors in the console.
